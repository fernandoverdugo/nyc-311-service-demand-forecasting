# Milestone 4 — Stakeholder Forecast Dashboard

## Purpose

Milestone 4 converts the validated forecasting results into a concise decision-support view for operational stakeholders.

The dashboard brings together four questions:

1. What level of citywide 311 demand should operations plan for?
2. How much uncertainty surrounds that forecast?
3. Which service categories are comparatively easy or difficult to forecast?
4. Where did category-specific models materially improve accuracy?

## Dashboard

**[Open the stakeholder dashboard](dashboard.html)**

The dashboard is generated from the committed analytical summaries under `data/metadata/` rather than from manually entered figures.

It presents:

- citywide 28-day demand forecast;
- preferred-model WAPE;
- empirical 80% and 95% planning ranges;
- illustrative staffing at the point forecast and upper planning bands;
- citywide model comparison;
- eight-category forecastability comparison;
- targeted model improvements for three volatile complaint types;
- a stakeholder-oriented decision takeaway.

## Planning view

The preferred citywide model forecasts approximately **10,842 requests per day**.

| Planning level | Demand | Illustrative staffing |
| --- | ---: | ---: |
| Point forecast | **10,842/day** | **284 FTE** |
| 80% upper planning band | **12,156/day** | **318 FTE** |
| 95% upper planning band | **12,820/day** | **336 FTE** |

The staffing conversion remains an explicit scenario assumption rather than an NYC staffing standard.

## Forecastability view

The dashboard makes the aggregation result visible:

- citywide preferred-model WAPE: **7.3%**
- median WAPE across eight high-volume complaint types: **28.8%**

This gap reinforces that a model performing well for aggregate demand should not automatically be applied to every service line.

## Targeted improvements

The dashboard also summarizes the category-specific improvements from Milestone 3:

| Complaint type | Baseline WAPE | Best model | Best WAPE | Improvement |
| --- | ---: | --- | ---: | ---: |
| HEAT/HOT WATER | 53.0% | Annual naive (365d) | **35.2%** | **33.5%** |
| Noise - Street/Sidewalk | 47.9% | Calendar/lag HGB | **30.7%** | **35.9%** |
| Street Condition | 34.1% | Calendar/lag HGB | **23.7%** | **30.4%** |

## Reproducibility

The dashboard is generated by:

```bash
python src/build_dashboard.py
python src/validate_dashboard.py
```

Semantic validation checks that the dashboard contains the current headline forecast, staffing values, model metrics, category metrics, and targeted-model results.
